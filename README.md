# IDATT2506 Applikasjonsutvikling for mobile enheter

Ovingene i emnet, høst 2026. Ett Android-prosjekt per oving under `exercises/`.

| Oving | Mappe | Frist |
| --- | --- | --- |
| 1 Introduksjon og installasjon | `exercises/exercise-01` | 28.09.2026 |
| 2 Composables, layout og tema | `exercises/exercise-02` | 28.09.2026 |
| 3 Tilstand og hendelser | `exercises/exercise-03` | 28.09.2026 |
| 4 ViewModel og navigasjon | `exercises/exercise-04` | 28.09.2026 |

Hvert prosjekt bygges med sin egen Gradle wrapper:

    cd exercises/exercise-01
    ./gradlew assembleDebug

`local.properties` er ikke sjekket inn. Legg inn din egen `sdk.dir` for å bygge.
